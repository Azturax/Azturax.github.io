About the studio

AZTRX Studio is the public face of Azturax — Minecraft companions, playable prototypes, and the tools around them. This site only lists repositories that are public on GitHub, so the catalog grows as projects ship.

Work is grouped by type: mods for Minecraft, games you can play, and tools that support the rest. New public repos are picked up automatically from the GitHub API.
